# 디자인 규칙

사이트의 화면을 만들 때 따르는 원칙, 토큰, 컴포넌트 규칙을 적는다.
아래 값은 화면 시안(홈, 프로젝트 상세, 노트 상세)에서 확정한 것이다(2026-11-26). Astro 이전 때 이 문서를 기준으로 구현한다.
현재 Jekyll + Chirpy 사이트에는 이 규칙을 적용하지 않는다.

## 원칙

- 프로젝트 화면은 그림을 먼저 보여 주고, 노트 화면은 읽기 편한 본문을 먼저 둔다.
- 꾸밈보다 내용의 구조를 드러낸다. 선, 번호, 배지는 정보를 담을 때만 쓴다.
- 색은 뜻이 있을 때만 쓴다. 강조색은 링크와 현재 위치에, 신호색은 확인이 필요한 곳에 쓴다.
- 움직임은 사용자의 조작에 답할 때만 넣는다. 화면에 들어올 때 나타나는 효과는 넣지 않는다.
- 확인되지 않은 내용은 비워 두지 않고 자리표시로 드러낸다. 가짜 수치나 예시 성과를 채우지 않는다.
- 다른 사이트의 배치, 문구, 그림을 옮겨 오지 않는다.

## 색

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `--bg` | `#f7f8f8` | `#0f1514` | 페이지 바탕 |
| `--surface` | `#ffffff` | `#151c1b` | 그림 상자, 시리즈 상자 |
| `--ink` | `#14201f` | `#e4e9e7` | 본문, 제목 |
| `--ink-2` | `#5d6b69` | `#9aa8a5` | 보조 글, 날짜, 그림 설명 |
| `--line` | `#d9dedd` | `#27302f` | 구분선, 테두리 |
| `--accent` | `#0e6b5c` | `#5fc7b2` | 링크, 현재 메뉴, 변환 화살표 |
| `--accent-soft` | `#e3efec` | `#17302b` | 검증됨 배지 바탕 |
| `--signal` | `#8f4c00` | `#e0a04a` | 확인 필요 표시, 진행 중 배지 |
| `--signal-soft` | `#f6ead9` | `#33260f` | 확인 필요 표시 바탕 |
| `--code-bg` | `#eef1f0` | `#1a2221` | 코드 바탕 |
| `--ax-x`, `--ax-y`, `--ax-z` | `#b8382b`, `#2c8050`, `#2b66ad` | `#e8776b`, `#63c48d`, `#74aaea` | 좌표축 도식의 X, Y, Z |

- 좌표축 색은 도식 밖에서 쓰지 않는다.
- 본문과 바탕, 보조 글과 바탕의 명도 대비는 구현 때 측정해 WCAG AA(4.5:1)를 넘는지 확인한다. 이 문서의 값은 아직 측정하지 않았다.
- 다크 테마는 시스템 설정을 따르고, 사용자가 바꾸면 그 선택을 기억한다.

## 글꼴과 크기

| 역할 | 글꼴 | 크기와 줄 간격 |
|---|---|---|
| 본문, 제목, 메뉴 | IBM Plex Sans KR (400, 500, 600, 700) | 본문 17px, 줄 간격 1.8 |
| 코드, 좌표 변환 표기 | IBM Plex Mono | 본문보다 한 단계 작게 |

- 글꼴은 사이트에서 직접 내려 준다. 외부 글꼴 서버를 부르지 않는다. 시안만 Google Fonts를 쓴다.
- 한글 줄바꿈은 `word-break: keep-all`로 어절 단위를 지킨다.
- 본문 폭은 `--measure: 42rem`, 넓은 화면의 전체 폭은 `--wide: 68rem`이다.
- 제목은 대문자 변환이나 자간 넓힘 없이 문장으로 쓴다. 제목 속 한 단어만 색을 바꾸는 강조는 하지 않는다.
- 고정폭 글꼴은 코드와 수식 표기에만 쓴다. 날짜나 라벨에는 쓰지 않는다.

## 배치

| 화면 | 구성 |
|---|---|
| 홈 | 연구 문제를 말하는 한 문장과 좌표계 도식, 연구 분야 목록, 대표 프로젝트, 최근 노트, 소개 |
| 프로젝트 상세 | 제목과 상태, 대표 그림, 사실 표(기간, 소속, 역할, 자료), Problem, Approach, Evaluation, Limitations, My contributions, 이력, 다음, 관련 노트 |
| 노트 상세 | 경로와 제목, 날짜와 태그, 시리즈 상자, 본문, 참고문헌, 이전 글과 다음 글, 오른쪽 목차 |

- 폭 분기는 860px와 700px 두 곳이다. 860px 아래에서 노트의 목차는 본문 위의 접이식으로 옮긴다. 700px 아래에서 여러 단은 한 단으로 쌓는다.
- 같은 속성을 가진 항목이 여럿이면 카드를 늘어놓지 않고 행 목록이나 표로 보여 준다.
- 메뉴는 Research, Projects, Notes, About 네 개다. 언어 전환은 메뉴 오른쪽에 둔다.

## 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 상태 배지 | 검증됨, 진행 중, 탐색 중, 구상 단계의 네 가지. 색과 함께 도형(채운 원, 반 원, 빈 원, 점선 원)으로 구분해 색만으로 뜻을 전하지 않는다 |
| 시험 조건 라벨 | 결과 옆에 시뮬레이션, 팬텀, 실제 데이터 가운데 어느 조건인지 적는다. 조건을 모르면 결과를 싣지 않는다 |
| 사실 표 | 프로젝트의 기간, 소속, 역할, 자료 링크를 한 줄로 둔다. 확인되지 않은 칸은 확인 필요로 표시한다 |
| 이력 | 날짜와 한 줄 설명의 목록. 실패한 시도도 적는다. 프로젝트 파일의 `history`에서 만든다 |
| 다음 | 날짜를 약속하지 않고 상태 배지로만 적는다 |
| 시리즈 상자 | "N편 중 M편"과 편 목록. front matter의 `series`, `seriesOrder`에서 만든다. 발행 전인 편은 준비 중으로 표시하고 링크를 걸지 않는다 |
| 그림 | 번호와 설명을 붙인다. 남의 그림은 출처와 사용 조건을 설명에 적는다. 그림마다 대체 텍스트를 쓴다 |
| 참고문헌 | 번호 목록, DOI 링크. 본문에서는 위 첨자 번호로 가리킨다 |
| 언어 전환 | 번역이 있는 페이지는 KO / EN 링크, 없는 페이지는 "한국어만 제공"으로 표시한다 |
| 자리표시 | 빗금 상자와 신호색 표시. 초안과 시안에서만 쓰고 발행된 페이지에는 남기지 않는다 |

## 그림과 도식

- 좌표계, 변환, 구조처럼 관계를 설명하는 그림은 SVG로 그린다. 테마에 맞춰 색이 바뀌도록 토큰을 쓴다.
- 변환 표기는 `T_image←patient`처럼 목적 좌표계를 앞에 두는 방식으로 통일한다.
- 의료영상, 환자 유래 데이터, 수술 영상은 공개 승인이 확인된 것만 싣는다. 판단 기준은 `AGENTS.md`의 공개 전 점검을 따른다.

## 접근성

- 키보드로 모든 링크와 버튼에 닿을 수 있어야 하고, 초점 표시가 보여야 한다.
- 제목은 `h1`부터 순서대로 쓴다. 메뉴, 목차, 시리즈 이동에는 이름을 붙인다.
- `prefers-reduced-motion` 설정을 따른다.

## 시안 위치

시안과 설계 보고서는 레포 밖의 비공개 작업 공간(`S_세컨드브레인`의 `blog` 폴더)에 있다. 이 레포에는 넣지 않는다.
